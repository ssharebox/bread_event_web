# 공용 교환 대장 붙이기

깃허브 페이지는 파일만 내려주는 곳이라 기록을 저장하지 못합니다.
구글 스프레드시트를 작은 서버로 쓰면 부스가 여럿이어도 한 곳에서 중복을 막을 수 있습니다.
전부 무료이고 10분이면 됩니다.

붙이고 나면 **구글 시트가 곧 교환 대장**입니다. 따로 엑셀을 관리할 필요가 없습니다.

## 1. 스프레드시트 만들기

1. 구글 드라이브에서 새 스프레드시트를 만듭니다.
2. 상단 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.

## 2. 코드 붙이기

1. 왼쪽 `Code.gs` 안의 내용을 전부 지우고, 같은 폴더의 `Code.gs` 내용을 붙여 넣습니다.
2. 저장합니다 (Ctrl+S).
3. 함수 목록에서 **시트만들기** 를 골라 실행하면 대장과 집계 시트가 미리 만들어집니다.
   (건너뛰어도 첫 교환 때 자동으로 생깁니다.)

담당자 확인 번호를 쓰려면 파일 위쪽 `const PIN = '';` 에 숫자를 넣으세요.

## 3. 웹앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴 → **웹 앱**
2. 설정
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**  ← 이게 `나만`이면 사이트에서 부를 수 없습니다
3. **배포** 를 누르고 권한을 허용합니다.
   "확인되지 않은 앱" 경고가 나오면 *고급 → 안전하지 않은 페이지로 이동*
4. **웹 앱 URL** 을 복사합니다. 끝이 `/exec` 여야 합니다.

## 4. 사이트에 주소 넣기

`index.html` 에서 아래 줄을 찾아 주소를 넣습니다.

```js
const LEDGER_URL = 'https://script.google.com/macros/s/.../exec';
```

저장하고 깃허브에 다시 올리면 끝입니다.

## 5. 확인

같은 폴더의 `점검.html` 을 브라우저로 열고 버튼을 눌러 보세요.
"기록했습니다" 가 나오고 스프레드시트에 줄이 쌓이면 성공입니다.
시험용 줄은 확인 후 지우시면 됩니다.

## 시트 구성

스크립트가 두 개를 만들어 줍니다.

**교환대장** — 교환 코드 · 발급 시각 · 교환 시각 · 담당자 · 비고
교환할 때마다 한 줄씩 쌓입니다. 담당자와 비고는 필요하면 손으로 적으세요.

**집계** — 교환 건수 · 오늘 교환 · 남은 수량
노란 칸에 준비 수량만 적어 두면 남은 수량이 자동으로 나옵니다.

## 동작 방식

| 상황 | 결과 |
|---|---|
| 처음 교환 | 시트에 기록되고 쿠폰에 사용 완료 도장 |
| 이미 교환된 코드 | 쿠폰을 여는 순간 사용 완료로 표시, 재교환 막힘 |
| 두 부스가 동시에 같은 코드 | 잠금이 걸려 한 곳만 통과 |
| 인터넷이 끊김 | 담당자에게 물어본 뒤, 승인하면 그 기기에서만 처리 |

## 주소를 넣지 않으면

`LEDGER_URL` 을 비워 두어도 사이트는 동작합니다.
다만 중복 확인이 기기 안에서만 이루어지므로, 부스가 하나이고
인터넷이 불안한 현장에서만 그렇게 쓰세요.

## 주의

- 배포 주소는 공개됩니다. 장난이 걱정되면 `PIN` 을 설정하세요.
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 편집 → 버전 새로 만들기** 로 다시 배포해야 반영됩니다.
- 인터넷이 끊긴 채 처리한 건은 시트에 없습니다. 코드를 적어 두었다가 나중에 손으로 넣으세요.
